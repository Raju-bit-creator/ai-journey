# Python ML service

`python/` is a standalone FastAPI service, deliberately not connected to the Next.js/NestJS stack. It trains and serves a `RandomForestClassifier` from scikit-learn on the classic Iris flower dataset (150 samples, 4 numeric features per sample — sepal length, sepal width, petal length, petal width — 3 species classes, perfectly balanced at 50 each).

`train.py` loads the dataset via `sklearn.datasets.load_iris()`, splits it 80/20 into train/test sets, fits the classifier, prints test accuracy, and saves the trained model plus class names to `model/iris_classifier.joblib` using `joblib.dump`. That file is gitignored — it's meant to be regenerated by rerunning `train.py`, not committed.

`app/main.py` defines two endpoints: `GET /health` and `POST /predict`. `/predict` accepts four floats (validated by a Pydantic model, `IrisFeatures`) and returns the predicted species plus a probability for each of the three classes, using the model's `predict_proba()`.

The dataset is very easy to classify — petal length alone almost perfectly separates the three species, with only a small overlap between versicolor and virginica — so the trained model reaches 100% accuracy on the test split. Predictions for points that fall in that small overlap region return less confident probabilities (e.g. 55/45 between two species) instead of 100%, since the model's underlying decision trees disagree in that region.

Uses Python 3.14, a plain `venv` + `requirements.txt` (no Poetry or uv), and has its own pytest suite in `tests/test_predict.py`.
